### Context & Purpose

This directory contains the foundational executive and strategic documentation of Quantum Flow Technologies:

- Strategic vision for enterprise Post-Quantum Cryptography (PQC) readiness.
- Four-month execution roadmap across cryptographic discovery, inventory (CBOM), risk assessment, migration orchestration, and continuous assurance.
- Governance, standards foundation (NIST FIPS 203, 204, 205; India DST Quantum-Safe Ecosystem Report; National Quantum Mission), and operating rhythm.

### Canonical Product Workflow

$$\textbf{Discover} \longrightarrow \textbf{Inventory} \longrightarrow \textbf{Prioritise} \longrightarrow \textbf{Plan} \longrightarrow \textbf{Migrate} \longrightarrow \textbf{Assure}$$

1. **Discover:** Find certificates, keys, protocols, and cryptography in code.
2. **Inventory:** Build an evidence-backed Cryptographic Bill of Materials (CBOM).
3. **Prioritise:** Score risk by exposure, data confidentiality lifetime, and migration complexity.
4. **Plan:** Dependency-aware migration packages and sequencing.
5. **Migrate:** Controlled PQC and hybrid changes with automated rollback.
6. **Assure:** Test, verify, and maintain the tamper-evident audit trail.
